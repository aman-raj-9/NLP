## 📚 Projects Overview

### 1. NLP Projects

A collection of notebooks and implementations covering fundamental NLP concepts.

- **Text Preprocessing:** Lowercasing, tokenization, punctuation removal, stopword removal, and lemmatization.
- **Text Representation:** One-Hot Encoding, Bag of Words (BoW), N-Grams, and TF-IDF.
- **Word2Vec:** Word embeddings, CBOW, Skip-Gram, and word similarity.
- **POS Tagging:** Part-of-Speech tagging and linguistic analysis using NLTK.
- **Text Classification:** Text feature extraction and machine learning classification techniques.
- **Saved Model:** Model artifacts saved for reuse in the relevant project.

### 2. Question Similarity Analysis

A machine learning project that compares two questions and predicts whether they are similar or different.

**Key concepts:**
- Text preprocessing and normalization
- TF-IDF vectorization
- Cosine similarity
- Common word ratio
- Feature engineering
- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- Model comparison and evaluation

The project compares multiple classification models and selects the best-performing model based on test accuracy. Results depend on the dataset and evaluation setup; larger datasets and further validation are needed for reliable real-world performance.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aman-raj-9/NLP.git
```

### 2. Navigate to the repository

```bash
cd NLP
```

### 3. Install the commonly used libraries

```bash
pip install numpy pandas scikit-learn nltk gensim beautifulsoup4 jupyter
```

### 4. Open the project

Open the repository in VS Code or start Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook you want to explore and run its cells in order. Some projects may require additional datasets, dependencies, or NLTK resources.
